# Fact-checking

Командный проект курса «Введение в LLM»: проверка фактов и их источников для исследовательских данных, редакционных материалов и, возможно, рынков прогнозов.

Первый эксперимент — проверка биографических событий для исследования участника команды. Polymarket остается гипотезой: на реализацию сценария и бэктест пока не коммитимся.

Сейчас здесь постановка и исследовательские материалы. Приложение, экспериментальный корпус и результаты оценки еще не подготовлены. Архитектура — предложение для обсуждения, стек не выбран.

Код, тесты и инструкции запуска будут добавляться вместе с реализацией. Выводы исследования храним в `research/`, актуальную постановку и требования — в `docs/`. Черновые отчеты агентов и история чата в командную документацию не входят.
