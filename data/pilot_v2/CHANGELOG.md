# v2: что улучшено относительно v1 (60 утверждений)

## Найденные проблемы v1
1. Жёсткая схема 2/2/2 на каждый документ: метки предсказуемы по структуре, а не по смыслу.
2. NEI-утверждения выдуманные и «шаблонные» («ровно миллиард», «ровно 12 миллионов»): модель может угадывать NEI по стилю, не проверяя источник.
3. REFUTES получены только искажением значения → есть риск лексического шортката.
4. Нет класса opinion/unverifiable, хотя он обязателен по заданию №33 (отметка мнений и непроверяемого).
5. Нет связи с новостями: утверждения без исходной новости, нет news-слоя.
6. 7 из 10 документов старые (2020–2024): LLM знает ответ из памяти, retrieval не проверяется.
7. Нет разбиения по событиям (в README названо, но не реализовано), нет пометки аннотатора и второй проверки.
8. Корпус 10 документов по 3–4 предложения: retrieval тривиален.

## Что сделано в v2
- 80 утверждений (+20): добавлены 14 утверждений из реальных новостей (ОИ-2026, ВОЗ WHS-2026) и 6 opinion/unverifiable.
- Поле `kind` (fact/opinion/unverifiable); правило: не-факты всегда NEI без evidence.
- Слой `news.jsonl` и поле `news_id`.
- `event_group` и `split` (dev/test) **по событиям**: проверено, что ни одна группа не лежит в двух сплитах.
- `origin_detail` (extracted / perturbed / unsupported_detail), признаки `has_number`, `has_date`, `has_exact_marker` для анализа шортката.
- `annotator`, `verified_by_second=false` — задел под вторую аннотацию и κ.
- Валидатор `validate_v2.py` (схема, ссылки на evidence, правила kind/label, утечки между сплитами).

## Не сделано (нужны люди/время)
- Вторая независимая аннотация и κ.
- Реальные (не искусственные) опровержения из СМИ.
- Естественные NEI (правдоподобные утверждения, которых нет в источниках), а не «ровно N».
- Свежие новости (ноябрь 2026) и больше документов; точный URL релиза ВОЗ (doc_012).
- Баланс: в v2 SUPPORTS 27 / REFUTES 24 / NEI 29; разбор по темам смещён в сторону CBR/CPI.
