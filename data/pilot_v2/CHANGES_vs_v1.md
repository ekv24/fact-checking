# Что изменено в работе одногруппника (датасет и документ)

Дата: 17.11.2026. Исходные файлы: `fact_checking_dataset.zip` (v1, 60 утверждений) и `Источники_данных_и_пилотный_датасет.docx`.

## Проблемы v1

1. Жёсткая схема 2/2/2 на документ: метки предсказуемы по структуре.
2. NEI выдуманные и шаблонные («ровно миллиард», «ровно 12 миллионов»): класс угадывается по стилю.
3. Опровержения получены только искажением значения.
4. Нет класса «мнение/непроверяемое», а задание №33 его требует.
5. Нет связи с новостями.
6. 7 из 10 документов за 2020–2024 годы: модель знает ответы из памяти.
7. Разбиение по событиям описано, но не реализовано; нет пометок об аннотаторе.
8. Корпус из 10 документов по 3–4 предложения: поиск тривиален.

## Что изменено в датасете (v1 → v2)

| Было (v1) | Стало (v2) |
|---|---|
| 60 утверждений, 10 документов | 80 утверждений, 12 документов, 4 новости |
| Только факты | Поле `kind`: fact / opinion / unverifiable (72 / 5 / 3) |
| 20 / 20 / 20 | SUPPORTS 27, REFUTES 24, NEI 29 |
| Нет связи с новостями | Файл `news.jsonl` и поле `news_id` |
| Нет разбиения | `event_group` и `split` (dev/test) по событиям, утечек нет |
| Нет пометок происхождения | `origin_detail` (extracted / perturbed / unsupported_detail) |
| Нет пометок разметки | `annotator`, `verified_by_second` |
| Нет анализа шортката | `has_number`, `has_date`, `has_exact_marker` |
| `build_dataset.py` | Добавлен `validate_v2.py`: схема, evidence, правила kind/label, утечки |

Добавлено 20 утверждений: 14 из реальных новостей (Олимпиада-2026, ВОЗ World Health Statistics 2026) и 6 оценочных/прогнозных. Исходные 60 утверждений не переписывались, к ним только добавлены поля.

## Что изменено в документе

Создан `Источники_данных_и_датасет_v2.docx`:
- обновлены состав, объёмы и баланс классов;
- добавлены разделы про мнения/прогнозы, разбиение по событиям, хранение и права;
- ограничения указаны честно (искусственные REFUTES, шаблонные NEI, старые документы, один аннотатор, нет κ);
- добавлен план доработки;
- в список источников добавлены итоги Олимпиады-2026 и доклад ВОЗ.

## Что не сделано

- Вторая независимая аннотация и расчёт κ.
- Естественные опровержения из СМИ и естественные NEI.
- Свежие новости за ноябрь 2026 года.
- Точный URL релиза ВОЗ (в v2 указан общий who.int).
