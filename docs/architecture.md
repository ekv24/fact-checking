# Предварительная архитектура

Предложение для первого эксперимента. Реализации и выбранного стека пока нет.

```text
Текст или таблица + доступные документы + границы проверки
    → выделение утверждений и событий
    → поиск фрагментов в документах / дополнительных источников
    → сопоставление свидетельств, конфликтов и пропусков
    → результат с цитатами и нерешенными вопросами
    → решение пользователя
```

| Часть | Ответственность |
| --- | --- |
| Вход и источники | Принять материал, сохранить происхождение и доступную версию документа; отметить недоступные источники |
| Выделение сведений | LLM извлекает события, участников, даты и проверяемые утверждения, сохраняя исходные фрагменты |
| Поиск | Найти относящиеся свидетельства в заданном корпусе; открытый поиск подключать по правилам задачи |
| Проверка | LLM сопоставляет смысл утверждения со свидетельством; обычный код проверяет форматы и поддерживает связи с источниками |
| Результат | Показать подтверждающие и противоречащие фрагменты, неопределенность и предлагаемые исправления; человек принимает решение |

Для исследовательского теста нужна отдельная проверка пропусков: сопоставление событий, найденных в документах, с уже заполненной таблицей. Проверка только существующих строк не обнаруживает отсутствующие записи.

Минимально сохраняем: идентификатор утверждения/события, исходное значение, документ и его версию, фрагмент или страницу, результат проверки и основание. Точный формат определим после выбора корпуса.

Начальный вариант — последовательный LLM-workflow с поиском: он позволяет отдельно проверить извлечение, поиск свидетельств и сопоставление. Поиск по предоставленному корпусу может использовать RAG. Несколько агентов нужны только при измеримом улучшении; разные ответы моделей не являются независимыми источниками.

Открыты выбор модели, поискового инструмента, хранения, интерфейса и критериев достаточности свидетельств. Структуру кода и тестов добавим вместе с реализацией. Результаты оцениваем по [плану первого чекпоинта](checkpoints/01-idea-and-data.md).
