# Метки triage

У технического тикета одна `Category` (`bug` или `enhancement`) и ровно одна `Triage` из таблицы. `Status` отражает ход исполнения.

| Роль и метка | Значение |
| --- | --- |
| `needs-triage` | Нужен разбор тикета |
| `needs-info` | Не хватает информации |
| `ready-for-agent` | Постановка готова для агента |
| `ready-for-human` | Требуется участие человека |
| `wontfix` | Принято решение отказаться от работы |

Готовность к исполнению определяют поручение, зависимости и правила трекера.
